Nidhogg لنظام Windows 10/11 x64

فك ضغط الحزمة كاملة، ثم شغّل Nidhogg.exe.
اختر مجلد اللعبة CUSA00920 الخاص بك، الذي يحتوي على eboot.bin ومجلد Data.
أو ضع مجلد CUSA00920 بجانب ملف التنفيذ وسيتم اكتشافه تلقائيًا.
ملفات اللعبة الأصلية غير مرفقة. لا تحتاج تثبيت أدوات تطوير أو VPN.
Options أو F1 يفتح شاشة إعدادات كاملة للعرض والصوت والتحكم والشبكة وبيانات الاتصال.
F3 يخفي أو يظهر بيانات الاتصال؛ ويمكن تخصيصها من HUD لإظهار التأخير فقط مثلًا.
هذه نسخة 1.1.0-rc.2 تجريبية للأونلاين؛ يجب تحديث نسخة اللاعبين معًا.
السيرفر على Azure في الإمارات ولا يعتمد على تشغيل جهاز المضيف.
افتح Multiplayer لعرض الجلسات العامة أو إنشاء جلسة عامة أو خاصة.
الجلسة الخاصة لها كود من ستة أحرف؛ اختر Join With Code للدخول بالكود.
المضيف يختار MAP ثم Start Game بعد اتصال اللاعب الثاني؛ لا توجد خطوة Ready.
تبدأ المباراة بنفس نافذة اللعبة دون إغلاقها وإعادة تشغيلها.
محدد 240 FPS يخص عرض الصورة؛ منطق اللعبة وحركتها الأصلية يعملان على 60 هرتز.
اترك تأخير الإدخال على Auto. اختبار شبكتين فعليتين لم يكتمل بعد.
للسيرفر إيقاف تلقائي لحماية الرصيد قرب 20 نوفمبر 2026.
تفاصيل الاختبارات والقيود في RELEASE-NOTES.md.
